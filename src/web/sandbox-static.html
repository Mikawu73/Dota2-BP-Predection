RESEARCH DEMO / LOCAL INFERENCE

Draft sandbox

The interactive sandbox runs locally with a Python service and a trained checkpoint. This GitHub Pages site publishes the dataset and experiment results only.

Run from your local checkout

python -m pip install -e .
python -m scripts.serve_demo --checkpoint PATH_TO_MODEL.pt

The sandbox opens at http://127.0.0.1:8765/sandbox after the service starts. A compatible trained checkpoint is required; model weights are not included in the repository.

No live prediction service is connected to this public page. The local model predicts the next pick or ban, not match win probability.
