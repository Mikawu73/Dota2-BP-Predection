# Demo assets

- `teams.json` is generated by `python -m scripts.build_team_catalog` from local
  OpenDota match details. Only public team IDs, observed names and aliases are
  retained. The latest observed name is not necessarily a team's current name.
  This catalog is for display only and is never used to train or score a model.

- `heroes.json` is a display-only subset (ID, name, portrait URL) of
  https://github.com/odota/dotaconstants/blob/master/build/heroes.json,
  retrieved 2026-10-12. It is not used as a source of gameplay statistics.
- Hero portraits are fetched by the browser from Valve's Steam CDN. Dota 2
  names and artwork belong to Valve. They are not bundled or relicensed here.
  Without internet access, labels and predictions still work.
- `lucide.min.js` is Lucide 0.468.0, retrieved from
  https://unpkg.com/lucide@0.468.0/dist/umd/lucide.min.js.
  Its license is preserved in `LUCIDE-LICENSE`.

Only heroes in the loaded checkpoint vocabulary are selectable. Catalog
presence does not establish availability in a particular game patch.
