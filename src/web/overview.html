07 / READING THE EVIDENCE

What these results do not establish

  • Validation was reused for model selection; no final neural test score is reported here.
  • Historical statistical test results were already exposed. Test data is not described as never inspected.
  • Actions from the same match are correlated. Uncertainty estimates should resample matches.
  • Behavior prediction is not optimal drafting. The independent value model remains exploratory.
